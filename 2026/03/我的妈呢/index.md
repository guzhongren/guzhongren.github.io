# 我的妈呢

我从家辉买了1/4个西瓜回家，打开门，西西和她哥哥正坐在地上玩耍，她突然说：“我的妈呢！”

我说：“妈妈在楼底下了。”

西西又说：“我的妈呢！”

我有说：“妈妈快上楼了。”

然后西西就不说话了，继续和她哥哥玩耍了。

我吃完饭后，妈妈给她穿好了衣服，我就带着她骑车去永宁门了。

回来的路上在小雁塔和朱雀大街相交的十字路口，我们看到了西瓜，西西抬起手指着西瓜突然说：“我的妈呢！”

我愣了一下才反应过来，西西说的是西瓜的英语，不是在问她妈妈在哪，然后我笑着说：“Watermelon，西瓜的英语叫 Watermelon, 不是我的妈呢。”

在回家的路上，西西不停的说着 `Watermelon`。
